# Reporting sensitive problems

Do not disclose credentials, participant data or an exploitable vulnerability in a
public issue.

Use GitHub's **Security > Advisories > Report a vulnerability** when private
reporting is enabled for this repository. If that option is unavailable, ask the
maintainer to arrange a private reporting channel without including sensitive
details in the public request.

Include the affected version/edition, operating system, reproducible steps and
likely impact. Redact personal data. Do not send real participant recordings unless
an appropriate private transfer and consent/data-handling arrangement is agreed.

This is an early project: no response-time guarantee or long-term support policy
has been established. Use the latest approved release candidate. The initial
release supports Windows as its primary target; other platforms are experimental.
